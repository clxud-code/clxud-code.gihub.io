# rclone / Google Drive

Статическая страница для требований Google OAuth при публикации личного
приложения rclone.

После включения GitHub Pages используйте:

- **Application home page:** `https://clxud-code.github.io/clxud-code.gihub.io/`
- **Application privacy policy link:** `https://clxud-code.github.io/clxud-code.gihub.io/privacy.html`
- **Authorized domains:** `clxud-code.github.io`

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** репозитория.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` (или вашу основную ветку) и папку `/(root)`.
4. Нажмите **Save** и дождитесь публикации.

> URL — это project page, потому что имя репозитория `clxud-code.gihub.io` не
> совпадает с форматом пользовательского сайта `<username>.github.io`.
